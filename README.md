# NameSpace

Адаптивная страница профиля по предоставленному референсу. React + TypeScript, сборка и сервер на Bun, без Vite.

## Запуск

```sh
bun install
bun dev
```

Открыть http://localhost:3000. Проверка типов и production-сборка: `bun run build`. Статические файлы появляются в `dist/`.

Вкладки переключаются мышью и клавиатурой. Кнопка редактирования открывает форму, настройки переключают тему, кнопка «Поделиться» копирует URL. Профиль и тема сохраняются в localStorage этого браузера. Статистика демонстрационная, разделы публикаций пустые, как в референсе. Серверная база данных и авторизация не подключены.
